# Chip Companion (optional)

**Not** the GrapeAncestry **v1.0.0** customer product. v1 output is the Docker UI → **`*.sample-first-v2.report.html`**.

This path is an optional classroom helper: **167K-site query VCF → `chip.json`**.

| Path | Output |
|------|--------|
| **v1 Docker product** | `*.sample-first-v2.report.html` (8501 / 8502) |
| **Optional Cloud JSON** | `chip.json` from a panel-site VCF |

Typical CLI (needs private assets / wired Streamlit — not a fresh public clone):

```bash
grapeancestry chip-report --vcf sample.vcf.gz --out chip.json
```

Science claim rules (OIV 225 only decision-grade, SDR proxy, etc.) match the main GUIDELINE — do not treat `chip.json` as a second “primary hand-in” for v1 customers.
