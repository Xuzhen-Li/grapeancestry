# grapeancestry

Intended home for the grapevine **167K capture** line: chip design and FASTQ → panel VCF → ancestry / identity / PCA.

**Status:** public placeholder. No runnable pipeline, no demo data, and no finished methods notes here yet. Do not treat this repo as a shipped analysis suite.

## Planned layout (empty for now)

| Path | Role when filled |
|------|------------------|
| [`chip/`](chip/) | Probe / SNP selection for 167K and follow-ons |
| [`analysis/`](analysis/) | Calling and report recipes |

The old standalone shell [grapevine-chip](https://github.com/Xuzhen-Li/grapevine-chip) redirects to `chip/`.

## This is not

- Not an aDNA authentication pipeline → [grapevine-adna](https://github.com/Xuzhen-Li/grapevine-adna)
- Not theory dossiers → [genomics-theory-mining](https://github.com/Xuzhen-Li/genomics-theory-mining)
- Not a nuclear pangenome / PAV graph → [vitis-pangenome](https://github.com/Xuzhen-Li/vitis-pangenome)

No unpublished genotypes, private coordinates, or sample-level matrices.
